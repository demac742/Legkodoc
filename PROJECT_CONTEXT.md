# Контекст проекта

## Продукт

Онлайн-сервис для создания простых юридических документов для физических лиц.

**Базовый поток:**  
Каталог → Страница документа → Конструктор → PDF с водяным знаком → Оплата → PDF без водяного знака.

MVP — это сервис **разовой покупки PDF**, а не SaaS.  
Никакой регистрации, подписок и личных кабинетов в MVP.

## Целевой пользователь

- Физические лица, которым нужен простой документ быстро.
- Люди, которые хотят заполнить документ с подсказками, а не искать шаблоны в Word.
- Пользователи, ищущие «образец документа», «скачать PDF» или «заполнить онлайн».

**Не в фокусе в MVP:** компании, B2B-договоры, корпоративный документооборот.

## MVP — что обязательно

- Каталог документов
- SEO-страницы каждого документа
- Конструктор с вопросами (а не длинная форма)
- Черновики в localStorage (отдельно для каждого документа)
- Бесплатный PDF с водяным знаком
- Платный чистый PDF после **подтверждения оплаты на бэкенде**

## MVP — что НЕ входит (жёсткий запрет)

- Аккаунты, логин, личный кабинет
- Подписки, регулярные платежи
- История документов, список покупок
- Экспорт в DOCX / Word
- Отправка PDF на email
- Админка
- Серверные черновики или облачное хранение
- Профили с повторяющимися данными / автозаполнение
- Промокоды, пакеты документов

## Первый документ

**Расписка о получении денег** (цена 49 ₽).  
Поля: город, дата, ФИО + паспорт + адрес обеих сторон, сумма цифрами (автоматическое прописью), основание, дата возврата (опционально).

Следующие документы (после стабилизации первого потока): Договор займа, Договор купли-продажи автомобиля, Акт приёма-передачи автомобиля, Договор аренды квартиры, Договор оказания услуг.

## Технологический стек (MVP)

- Next.js + TypeScript + Tailwind CSS
- Next.js API routes (бэкенд)
- localStorage для черновиков (база данных не нужна в MVP)
- Генерация PDF: Puppeteer или Playwright (HTML → PDF)
- Оплата: ЮKassa; доступ к чистому PDF только после подтверждения оплаты на бэкенде

## Ключевые ограничения (всегда соблюдать)

- Бесплатный PDF: водяной знак «ЛЕГКОДОК» на каждой странице, повторяется по диагонали, текст читаем.
- Чистый PDF: только после **подтверждения оплаты на бэкенде** — никогда по состоянию фронтенда.
- Юридический смысл: никогда не менять без явного указания.
- Документы должны быть конфигурируемыми (добавление новых документов без переписывания логики).

## Визуальное направление

Спокойный, современный, документо-ориентированный сервис:

- Белый или светло-серый фон
- Чёрно-бело-серая палитра
- Тёмный текст, чистая типографика
- Спокойный, внушающий доверие тон
- **Никаких** ярких цветов, тяжёлых градиентов или стартап-визуала
- **Не копировать** дизайн и брендинг dogovor.ru
